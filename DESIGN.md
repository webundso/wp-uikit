# Design Tokens – Spickzettel

## Farben
| Token      | Bedeutung                        | Typisch |
|------------|----------------------------------|---------|
| primary    | Hauptfarbe                       | Grün    |
| secondary  | Sekundärfarbe / Akzent           | Blau    |
| danger     | Fehler, Warnungen                | Rot     |
| muted      | Hilfselemente, Editor-Hinweise   | Grau    |
| text       | Fliesstext                       | Schwarz |
| background | Seitenhintergrund                | Weiss   |

## Typografie
- base     → Fliesstext (Inter)
- heading  → Überschriften (Source Serif 4)

## Spacing
- xs → 4px
- s  → 8px
- m  → 16px
- l  → 24px
- xl → 40px
